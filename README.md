# 🔐 Key Principles of Cloud Security

## 📌 Club Task – Infographic Design

This repository contains my infographic design created as part of the **Aurix Club** task.

The infographic explains the **Key Principles of Cloud Security** through a simple and visually engaging design.

## 🛡️ Topics Covered

The infographic highlights five important principles of cloud security:

1. **Identity & Access Management (IAM)**
   - Multi-Factor Authentication (MFA)
   - Access control for authorized users

2. **Data Encryption**
   - Encryption of data at rest
   - Encryption of data in transit

3. **Continuous Monitoring & Auditing**
   - Automated logging
   - Real-time threat detection
   - Anomaly detection

4. **Regular Vulnerability Assessments**
   - Automated security scans
   - Penetration testing
   - Proactive security patching

5. **Robust Backup & Disaster Recovery**
   - Immutable backups
   - Business continuity
   - Protection against ransomware and outages
